FORGE // SOLO v1

This is NOT a public social app.
It is a private, single-player gaming career universe built around one person.

CORE SYSTEMS INCLUDED
- Account level + XP
- Career score + career tiers
- Game library
- Per-game mastery
- Session logging
- Playtime tracking
- Current / now-playing game
- Quest system with normal, daily, weekly and completed sections
- Quest progress + XP rewards
- Skill tree with upgrade points
- Achievements
- Clip archive
- Personal record book
- Vault for loadouts, builds, notes, links and ideas
- Personal seasons / battle pass
- Season levels + reward track
- Career timeline
- Activity heatmap
- Profile customization
- Light/dark mode
- Command palette (Ctrl/Cmd + K)
- Local-first storage
- JSON export / import
- Offline-capable PWA
- Responsive mobile layout

HOW TO RUN
Fastest:
1. Unzip this folder.
2. Open index.html.

Better on Windows:
1. Double-click launch.bat
2. Browser opens localhost:8080
3. You can install it as an app from a supported browser.

IMPORTANT
Data is stored in your browser on that device.
Use Settings > Export Backup before moving devices or clearing browser data.
