FORGE // DAILY v2

THE ENTIRE DAILY LOOP:
1. Open FORGE.
2. You get 5 random quests for VALORANT and VRFS.
3. Do a quest in-game.
4. Clip the moment.
5. Attach the clip to the quest.
6. The quest completes and gives XP.

THAT'S IT.

WHAT V2 DOES
- Exactly 5 daily quests
- Only VALORANT and VRFS
- Large quest pools for both games
- Deterministic daily generation
- Balanced / VAL-heavy / VRFS-heavy / fully random mixes
- One full-board reroll before you complete anything
- Clip or screenshot required to complete a quest
- Clips are stored locally in IndexedDB on your device
- Built-in clip library and player
- XP and account leveling
- +250 XP perfect-day bonus for completing all 5
- Daily streak and longest streak
- VALORANT / VRFS career counts
- Unlockable titles
- Daily history
- Dark/light mode
- Backup/restore of progression and quest history
- Responsive tablet/mobile layout
- Offline PWA support when hosted over localhost/HTTPS

IMPORTANT ABOUT CLIPS
The actual video/image files are stored inside the browser on that device.
JSON backups contain progression and metadata, NOT the video files themselves.
Browser storage has a limit, so trimming clips before attaching them is a good idea.

HOW TO RUN
Fast: open index.html.
Better on Windows: run launch.bat and open http://localhost:8080.

For GitDrop / GitHub Pages:
Upload this ZIP as the update. index.html is at the ZIP root.
